学生端使用教学

就三步：① 选项目 → ② 智能填表 → ③ 查结果，全程大概 3 分钟 ⏱️
💡 一句话版：挑个项目 → 简历 / 口述自动填表 → 校对后提交 → 把提交码发给主办方 → 回来查结果。
STEP 1 · ⭐ 选一个你想报名的项目
切到「① 项目选择与切换」。主页里已经有的项目，直接点「选这个项目」就行 —— 不需要你上传微信链接， 因为主办方早就把官方链接传好了。
点完会 自动跳到「招募要求解析」，把硬性条件、加分项、招募人数和要准备的材料都摊开给你看。
想换？点另一个项目的「选这个项目」即可随时切换；也可以点「回首页切换项目」去招募页慢慢挑。
STEP 1.5 · 🔗 主页里没有的项目怎么办（选填）
只有当你想报的项目 不在主页列表里，才需要展开「二、主页里没有这个项目？」， 粘贴它的公众号链接后点「抓取链接正文」，或上传招募文件或粘贴全文。
硬条件 / 加分项 / 招募人数要点了「解析招募要求」才会弹出来，不会突然冒出来吓你一跳。
STEP 2 · 📝 智能填表与上传材料
在 ① 里点「下一步：去 ② 智能填表 →」，或直接切到「② 智能填表与上传材料」。
懒人三件套：上传简历识别 / 语音快速填表（对着嘴皮子讲一段自我介绍）/ 粘贴简历文本， 系统会一次性把姓名、学号、年级、专业、邮箱、技能勾选全都自动填好。
⚠️ 自动填完一定要自己逐项校对，机器人偶尔也会看走眼 🤖
该项目专属的问题（比如「为什么想参加」）会自动生成在基本信息下面；带 * 的是必填。
最后到「八、上传材料」登记材料文件名，点「提交报名」。
STEP 3 · 🎟️ 保存好你的提交码
提交成功后会生成一串 提交码。复制发给主办方，或下载「报名包 .json」交给主办方一键导入。
本机记录 不会跨设备、跨浏览器同步，提交码就是你的凭证，记得存好 📌
STEP 4 · 🔍 查询报名结果
切到「③ 报名查询」，输入报名时填的 姓名 + 学号，点「查询」。
结果会俏皮地告诉你：还没提交 🙈 ／ 还在加载中 ⏳ ／ 报名成功啦 🎉 ／ 恭喜录取，快去联系老师 🌟
🔒 关于隐私：所有数据都只存在 你这台设备的浏览器 里，不会自动上传到任何服务器； 清理浏览器缓存会清掉记录，所以提交码请一定保存好。手机号对外展示时会自动脱敏。

一键导入所有邮件 → 直接出评选结果

你现在邮箱里已经堆了很多报名邮件：整包丢进来就行。系统会 逐封拆邮件 → 取出发件人与附件 → 按人归档 → 解析简历与作品集 → 直接产出评选结果，全程不用再点「运行筛选」。
怎么把 QQ 邮箱的邮件拿出来（任选一种，推荐第 1 种）：
① Foxmail 客户端登录 QQ 邮箱 → 在收件箱里 Ctrl/⌘ 多选（或按发件人排序整段选中）→ 右键 「导出邮件 / 另存为」 → 得到一批 .eml 文件 → 全选丢进来；
② 把邮件附件按人分文件夹下载好 → 用「导入整个文件夹」；
③ 已打包成 ZIP 的（含 .eml 或材料文件）→ 用「一键导入材料包」。
认人顺序：邮件发件人姓名 → 邮件主题 / 邮箱前缀 → 上一级文件夹名 → 文件名前缀； 附件按文件名认类型（须含「报名表 / 简历 / 作品集 / 成绩单 / 陈述」），邮件正文会自动当作个人陈述参与解析。

使用教学

三步上手：建项目 → 收材料 → 看结果
① 主办方 · 建项目
在「① 项目库」粘贴公众号文章链接 → 点「解析并发布到首页」，自动生成海报与截止时间；或点「导入本地文档 / 抓取链接」手动建。在「我的项目库」可编辑、删除任意项目。
② 主办方 · 收材料 & 筛选
切到「② 导入材料与 AI 筛选」，先把学生材料（报名表 / 简历 / 作品集…）打包导入；点「运行筛选」本地 AI 自动初筛。点「查看 AI 筛选结果」查看推荐 / 待定 / 淘汰与原因；点「候选人库与联系方式」复制邮箱、拨打电话、一键发录取文案。
③ 学生 · 报名
在「① 项目选择与切换」选好项目，可粘贴 / 上传招募要求后点「解析」看条件；切到「② 智能填表与上传材料」，上传简历或语音填表，系统自动填充，校对后提交，提交码发给主办方即可。
④ 数据怎么互通（为什么现在要靠提交码）
纯静态页、没有服务器，学生的数据只存在他自己的浏览器里，所以没法自动飞到你这里 —— 目前提供三条路：
　A · 邮箱直达（推荐先开）：在「① 项目库 → 方式〇」填好你的收件邮箱，学生提交后点「📧 一键发给主办方」即可邮件送达；
　B · 提交码 / 报名包：学生复制提交码发你，你在这里粘贴或上传 .json 导入；
　C · 整包批处理：把邮箱里的附件按人分文件夹下载，用「② 一键导入材料包」一次性导。
想彻底不用学生手动发送，必须有一处「两边都能读写的云端」——见下方「关于微信小程序」。
⑤ 关于微信小程序：能不能彻底免掉提交码？
结论：光做小程序本身解决不了，必须配「云开发」才行。小程序本质也只是个客户端，数据只写在手机本地的话，主办方照样看不到。
本项目已经把这条路写好了（在 `screener-miniprogram/` 小程序目录里）： 学生提交 → submitApply 云函数直写云数据库 candidates 集合 → 主办方小程序首页 / 候选人库读同一张表实时看到； 再由 notifyNewApply 云函数用订阅消息把「有新的报名」推到你微信，点开直达候选人库。
好处：不用买服务器、不用备案域名、不用自建运维，且彻底免掉提交码。你需要做的只有一次性配置： 申请订阅消息模板 ID → 填进 `config/env.js` 与 `cloudfunctions/notifyNewApply/env.js` → 部署 `notifyNewApply` 云函数 → 在小程序首页点「🔔 开启 / 续期提醒」授权（订阅消息是接收方授权，所以要你点，不是学生点）。
详见 `README.md` 第三节第 5 条。在这套配好之前，请先用上面的「A · 邮箱直达」或「一键导入所有邮件」把流程跑通。
提示：本地数据会随浏览器清理而丢失，重要内容请定期在「① 项目库 → 数据同步与离线存储」导出备份。
