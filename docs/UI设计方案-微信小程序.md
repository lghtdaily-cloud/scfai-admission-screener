# 川美课题招募筛选 · 微信小程序 UI 设计方案 v1.0

> 目标端：微信小程序（`screener-miniprogram/`）
> 设计原则：美观 + 易用 + 符合微信用户习惯
> 推荐配色：**方案 B · 青黛**（青紫 / 淡黄 / 白）

---

## 一、设计目标与约束

### 1.1 用户画像

| 角色 | 场景 | 关键诉求 |
|---|---|---|
| 学生（本科生 / 研究生） | 课间、宿舍，手机单手操作 | 3 分钟看懂项目、填完表、知道结果 |
| 主办方（教师 / 导师） | 办公室，电脑 + 手机混用 | 批量导入邮件、一键筛选、快速定人 |

### 1.2 微信小程序硬约束（设计必须遵守）

- **主包 ≤ 2MB**：不引入大型 UI 库；图标优先用内联 SVG / 字体图标子集，不用整套 iconfont
- **首屏 ≤ 1.5s**：首屏只请求必要数据，列表分页加载
- **导航层级 ≤ 5 层**：学生端与主办方端用「角色切换」而非深层跳转
- **tabBar 最多 5 项**：学生端 4 项，主办方端独立 tabBar
- **点击热区 ≥ 44×44px**：微信设计规范硬要求
- **不能用 DOM 操作**：所有交互靠 `setData` + `wxss` 状态类

## 二、色彩系统

### 2.1 方案对比（已出预览图）

| 方案 | 色系 | 气质 | 适用判断 |
|---|---|---|---|
| A · 竹青 | 灰绿 #4A6B5A / 米黄 #E8D9A8 / 白 #F7F5EE | 沉静克制，宣纸青竹 | 长时间看筛选列表最护眼，但艺术感偏弱 |
| **B · 青黛（推荐）** | 青紫 #3D3568 / #6B5FA8 / 淡黄 #F5D97A / 白 #FAF9FC | 艺术而不轻浮 | 学生端亲切、主办方端专业，两端通吃 |
| C · 陶土 | 赭红 #8C4A32 / #C2683F / 麦黄 #EFC96B / 米白 #FBF6F0 | 雕塑窑火，美院气最浓 | 视觉最独特，但长时间筛简历易疲劳 |

**推荐 B 的理由**：青紫对应川美视觉识别中的「靛」，淡黄做高亮（截止倒计时、新提交提醒），白底保证长列表可读性。

### 2.2 方案 B 完整色板（可直接写进 `app.wxss`）

```
/* ===== 主色 Primary ===== */
--brand-900: #26215C;   /* 最深，标题文字 */
--brand-800: #3D3568;   /* 深色卡面、头部渐变底 */
--brand-600: #534AB7;   /* 主按钮、链接、强调文字 */
--brand-400: #6B5FA8;   /* 主按钮填充、图标 */
--brand-200: #ABA2D9;   /* 深底上的次要文字 */
--brand-100: #CECBF6;   /* 标签底 */
--brand-50:  #EEEDFE;   /* 极浅底、选中态 */

/* ===== 强调色 Accent ===== */
--accent-600: #E0A03C;  /* 深黄，图标描边 */
--accent-400: #F5D97A;  /* 主强调：倒计时、新提交、CTA */
--accent-100: #FDF3D0;  /* 浅黄底 */

/* ===== 中性 Neutral ===== */
--ink-900: #1A1A1A;     /* 正文主色 */
--ink-600: #5F5E5A;     /* 次要正文 */
--ink-400: #888780;     /* 辅助说明、占位 */
--line:    #DCDAE8;     /* 分隔线、描边 */
--surface: #FFFFFF;     /* 卡片面 */
--page:    #FAF9FC;     /* 页面底 */

/* ===== 语义色 Semantic ===== */
--success: #1D9E75;  --success-bg: #E1F5EE;   /* 录取 */
--warn:    #BA7517;  --warn-bg:    #FAEEDA;   /* 待定 */
--danger:  #A32D2D;  --danger-bg:  #FCEBEB;   /* 淘汰 / 错误 */
--info:    #185FA5;  --info-bg:    #E6F1FB;   /* 提示 */
```

### 2.3 配色使用规则

- **一屏一个主 CTA**：主按钮用 `--brand-400` 实底，一屏内不出现第二个同强度按钮
- **淡黄只做「时间 + 新」**：倒计时、新提交标记、次要 CTA（黄底 + 深紫字，对比度达标）
- **深紫底只用于「头部」和「核心工具卡」**：不超过屏高 1/3
- **语义色互斥**：录取绿 / 待定黄 / 淘汰红，同一候选人只出现一种

## 三、字体与排版

### 3.1 字号阶梯（rpx，750 设计稿）

| 用途 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 页面大标题 | 44rpx | 600 | 1.3 |
| 卡片标题 | 32rpx | 600 | 1.4 |
| 正文 | 28rpx | 400 | 1.6 |
| 辅助说明 | 24rpx | 400 | 1.5 |
| 标签 / 角标 | 22rpx | 500 | 1.2 |
| 数据大数 | 56rpx | 600 | 1.1 |

### 3.2 排版规则

- **中英文混排自动加空格**：`AI 生成艺术` 而非 `AI生成艺术`
- **数字用等宽特性**：分数、人数、倒计时用 `font-variant-numeric: tabular-nums`
- **正文最大行宽**：手机上不限制，但说明文字单行不超过 20 个汉字
- **段落间距**：段间 24rpx，列表项间距 16rpx

## 五、卡通引导角色「小川」

### 5.1 角色设定

- **原型**：猫头鹰 —— 审阅、洞察、守夜，与「筛选候选人」语义天然契合
- **名字**：**小川**（川美 + 川流不息）
- **配色**：身体青紫 `#6B5FA8`，腹羽淡黄 `#F5D97A`，喙橙 `#E0A03C`
- **性格**：沉稳、话少、偶尔冷幽默（符合「帮你盯着」的助手定位）

### 5.2 三种表情状态（已出预览图）

| 状态 | 视觉特征 | 使用场景 |
|---|---|---|
| **默认 · 欢迎** | 圆眼 + 瞳孔高光，翅膀自然下垂 | 首页首屏问候、使用引导首步 |
| **提示 · 有发现** | 眯眼（眉毛弧线）+ 单翅上举 + 气泡点亮 | 「检测到 24 份新提交」「发现截止临近」 |
| **成功 · 录取** | 弯月笑眼 + 双翅张开 + 两侧星芒 | 提交成功、筛选完成、查询结果为推荐 |

### 5.3 角色使用规范

- **只在关键时刻出现**：首屏问候、引导步骤、空状态、结果页。日常列表页不出现，避免干扰
- **尺寸**：引导页 160rpx，空状态 120rpx，内联提示 48rpx
- **不参与主流程操作**：角色是「旁白」，所有操作仍由按钮承担
- **引导词 ≤ 30 字**：一句话说完，不啰嗦

### 5.4 SVG 资源落地

角色为纯路径 SVG，可直接放进 wxml（`<image src="data:image/svg+xml,...">` 或存为 `assets/xiaochuan-*.svg`）。
建议导出 3 个状态文件 + 1 个 `xiaochuan-idle` 微动效版（眨眼，`@keyframes` 只动 `transform` / `opacity`）。

## 六、页面结构

### 6.1 学生端（tabBar 4 项）

```
① 招募   → 项目列表 + 详情 + 报名入口
② 报名   → 智能填表 + 材料上传 + 提交回执
③ 进度   → 报名查询 + 状态时间线 + 联系老师
④ 我的   → 已报名项目 / 收藏 / 使用引导重看
```

### 6.2 主办方端（tabBar 4 项）

```
① 工作台 → 数据概览 + 一键智能筛选（主 CTA）+ 导入邮件
② 候选人 → 列表（按分数排序）+ 详情 + 评价明细
③ 项目   → 新增 / 编辑 / 上下架
④ 设置   → 接收邮箱、订阅消息续期、导出 Excel
```

### 6.3 角色切换

首屏选择「我是学生 / 我是主办方」，之后可在「我的」中切换。**不混用同一套 tabBar**，避免学生看到教师功能。

## 七、关键页面规格

### 7.1 学生端 · 招募首页

- 顶部：深紫 `#3D3568` 圆角卡（高约 320rpx），含川美标识 + 小川问候语
- 主体：项目卡列表，每张卡含 `标题 / 剩余天数角标 / 招募人数 / 标签`
- 天数为 0~7 天时角标转 `--accent-400` 淡黄底，强化紧迫感
- 底部固定 CTA：「选好项目，一键智能填表」（`--brand-400`）
- 空状态：小川 + 「暂时没有进行中的招募」

### 7.2 主办方端 · 工作台

- 顶部：白色标题卡「主办方工作台 / 筛选与录取」
- 指标区：2×2 网格 —— `待筛选 / 已推荐 / 已淘汰 / 项目数`，大数 56rpx
- 核心卡：深紫底「一键智能筛选」卡，含放大镜 SVG + 副标题「七维评分 · 自动出结果」+ 淡黄主按钮
- 快捷区：`导入邮件` / `候选人库` 两个白色小卡并排
- 动态区：最新提交列表（头像圆点 + 姓名 + 项目 + 相对时间 + 「新」角标）

### 7.3 候选人详情（主办方）

- 顶部：头像 88rpx + 姓名 + 总分（大字 56rpx）
- 七维评分：横向条形图，每维显示 `得分 / 满分`
- 优势 / 不足：双列标签区（绿底 / 橙底）
- 评价明细：可折叠，默认收起避免信息过载
- 底部固定双按钮：`淘汰`（次按钮） / `推荐`（主按钮）

## 八、动效规范

- **时长**：入场 240ms，状态切换 160ms，微交互 120ms
- **缓动**：`cubic-bezier(.2,.8,.2,1)`
- **可动元素白名单**：`transform` / `opacity` 只说这两个属性，避免 reflow
- **禁止**：渐变闪光、粒子爆炸、超过 400ms 的转场
- **加载态**：骨架屏，不用转圈超过 1.5s 的情况
- **触觉反馈**：仅在「提交成功」和「筛选完成」调用 `wx.vibrateShort`

### 使用引导（首次进入）

复用网页版已验证的 spotlight 方案：背景压暗 `rgba(10,14,26,.76)`、白色描边挖洞、白色提示卡。
小程序版改为 `cover-view` + `movable-area` 实现，步骤 4~6 步，`wx.setStorageSync('screener_tour_v1')` 标记已读。

## 九、无障碍与易用性

- **对比度**：正文对背景 ≥ 4.5:1；淡黄 `#F5D97A` 上只能用深紫字 `#3D3568`，不可用白字
- **不只靠颜色传达**：录取 / 待定 / 淘汰除颜色外必须带文字
- **点击热区**：可点元素视觉尺寸 ≥ 32rpx 时，用 padding 撑到 ≥ 44px
- **错误提示**：就近显示在出错字段下方，不用全局 toast
- **表单**：必填项标 `*`；提交前整表校验并滚动到第一个错误项

- 不改动任何业务逻辑与云函数，**本轮纯 UI**
