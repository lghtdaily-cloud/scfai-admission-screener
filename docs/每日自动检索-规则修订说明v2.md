## 二、一个必须告诉你的硬约束

你要的「从微信公众号摘取链接」这件事，**技术上做不到自动化**。我做了 5 组实测：

| 测试 | 结果 |
|---|---|
| ① 微信检索脚本返回的链接类型 | 是 `weixin.sogou.com/link?url=...` **中转链接**，不是真实微信链接 |
| ② 中转链接能否自动解析 | **6/6 全部触发验证码**，成功率 0% |
| ③ 直接探测搜狗中转链接 | `302 → antispider`（反爬拦截页） |
| ④ 限定域搜索 `mp.weixin.qq.com` | 返回结果 **URL 字段为空** |
| ⑤ 脚本自带 `-r` 解析参数 | 返回 **0 条** |

**原因**：
1. 搜狗有反爬验证码墙，程序进不去
2. 微信公众号内容对外封闭，文章链接只能在微信 App 内打开，外部搜索引擎无法稳定索引

**说白了**：微信链接只能"从微信里拿"，而所有外部工具都进不去微信。这是平台设计，不是技术没调对。

## 三、我的解决方案：复制标题搜微信

既然拿不到链接，就**不依赖链接**。

### 前端已改（已验证）

卡片按钮根据链接情况自动切换：

| 情况 | 按钮 | 行为 |
|---|---|---|
| 有微信链接 | 「详情」 | 直接打开原文 |
| 无链接 / 非微信链接 | **「复制标题用微信搜」** | 一键复制「公众号名 + 标题」 |

点「详情」遇到非微信链接时，也会弹确认框提醒改用复制。

**新增 4 处代码**（`dist/index.html` + `webapp/index.html` 均已打补丁）：
1. `isWxUrl()` —— 判断链接是否为微信
2. `copyWxHint()` —— 复制「公众号名 + 标题」，含 Clipboard API + 降级方案
3. 卡片按钮条件渲染
4. `openSource()` 兜底引导

### 使用体验

用户看到活动卡片 → 点「复制标题用微信搜」 → 粘贴到微信搜索框 → **第一条就是原文**

这样：
- ✅ 永远不会点开打不开的链接
- ✅ 所有信息都能在微信里找到原文
- ✅ 完全自动，无需人工维护链接
