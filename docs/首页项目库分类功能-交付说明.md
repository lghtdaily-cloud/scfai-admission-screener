### 2. 二级「区分」标签

内置 **40 个重庆区县 / 新区**词库：沙坪坝、渝北、渝中、九龙坡、南岸、江北、大渡口、北碚、巴南、璧山、永川、涪陵、合川、江津、长寿、铜梁、潼南、荣昌、大足、綦江、万州、黔江、武隆、巫山、奉节、云阳、开州、梁平、城口、丰都、垫江、忠县、石柱、秀山、酉阳、彭水、两江新区、高新区、西部科学城。

标题或主办方里出现区县名时，卡片上自动追加一个灰色的 `📍 区县名` 标签。

### 3. 自动推断，零维护

- 新增 `inferCategories(p)`：从 `title + org + summary + parsed.hard` 拼成文本，用正则匹配推断分类，一条项目可同时属于多个分类。
- 新增 `ensureCats(p)`：渲染前自动补全 `p.cats` 和 `p.district` 字段，**老数据不需要手工改**。
- `renderProjects()` 开头执行 `DB.projects.forEach(ensureCats)`，保证每次渲染分类都是最新的。

### 4. UI 变化

**首页筛选区**（搜索框下方）新增一条分类栏：

```
项目分类  ▦全部分类(4)  📖学术类(2)  🛠实践类(4)  🎓川美(4)  📍重庆(4)  🏛全国院校(0)
```

- 每个分类标签右侧带**实时条目数**
- 选中态：蓝底白字 + 轻投影
- 与原有的时间筛选（全部 / 进行中 / 7 天内截止 / 已截止）**叠加生效**，互不冲突

**项目卡片**左上角新增分类标签行，例如：

```
📖 学术类  🛠 实践类  🎓 川美  📍 重庆
```
