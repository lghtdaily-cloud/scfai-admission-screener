# 川美课题招募筛选 · UI 设计方案 v3

> 目标端：微信小程序
> 本版两个核心变化：
> ① **单任务原则** —— 每屏只做一件事，详细信息靠点击进入新页面，不堆在一屏
> ② **吉祥物极简化** —— 3D 渲染小圆球，去掉黄色腹羽与所有多余部件，只留眨眼与微笑，可四向跳跃

---

## 一、原则一：单任务页面（最重要的结构决策）

### 1.1 为什么手机上必须拆页

手机屏幕的物理限制决定了：
- 一屏能舒适阅读的信息量 ≈ **一个标题 + 一段话 + 一个动作**
- 用户是单手操作、注意力碎片化，滚动找东西的成本极高
- 内容一多，用户就不知道"现在该干嘛"

艺术馆网站的同类做法：**首页只负责让你"走进展厅"，展品详情在下一层。**

### 1.2 学生端页面链路（每屏一件事）

```
L1 首页           → 只做「选」：看海报、横向切换项目、点进详情
   ↓ 点海报
L2 项目详情       → 只做「读」：需求、截止时间、要准备什么
   ↓ 点「开始报名」
L3 报名填表       → 只做「填」：一份表单，分段填，底部固定提交
   ↓ 点「提交」
L4 提交回执       → 只做「看」：提交码 + 邮件回执入口

L1 首页           → 查进度入口
   ↓
L5 报名进度       → 只做「查」：三节点时间轴
   ↓
L6 筛选结果       → 只做「知」：录取 / 待定 / 未选 + 一句说明
   ↓ 录取时
L7 联系老师       → 只做「联」：老师联系方式
```

### 1.3 主办方端页面链路

```
L1 工作台       → 只做「概览」：4 个指标 + 一个主 CTA
   ↓ 点「一键筛选」
L2 候选人列表   → 只做「扫」：按分排序，一屏看 6~8 人
   ↓ 点某个人
L3 候选人详情   → 只做「判」：七维评分 + 优势不足 + 推荐/淘汰
   ↓
L4 项目库       → 只做「管」：新增 / 编辑 / 上下架
L5 设置         → 只做「配」：接收邮箱、订阅消息、导出
```

### 1.4 拆页四条硬规矩

1. **一屏一个主动作。** 首页只"选"、详情只"读"、填表只"填"，不混用。
2. **详情放独立页，不做卡片内展开。** 手机上展开会把上下文挤走，用户立刻迷失位置。
3. **返回永远可见。** 用小程序原生左上角返回，页面内不重复放"返回"按钮。
4. **tabBar 最多 4 项。** 学生端与主办方端各一套，首屏先选角色。

### 1.5 一屏的信息预算

| 区块 | 屏高占比 | 内容 |
|---|---|---|
| 头部 | 28% | 标题 + 可选吉祥物问候 |
| 主体 | 52% | **只放一个核心对象**（一张海报 / 一段需求 / 一份表单） |
| 操作 | 20% | 一个主按钮，固定在底部 |

## 二、原则二：字体与几何

### 2.1 艺术馆网站的字体策略

| 站点 | 字体 | 做法 |
|---|---|---|
| The Broad | grotesque sans | **全站只用无衬线**，导航标签全大写 |
| 荷兰国立博物馆 | humanist sans | 人文无衬线，标题加粗，正文标准行高 |
| 澳洲博物馆 | Apercu | 无衬线多字重，标题行高 110% |
| NMAAHC | Freight | **衬线用于展览文本 + 无衬线大写用于标志**，两者混排 |

**结论**：艺术馆的主流做法不是"用花哨字体"，而是**单字族 + 严格字重层级 + 精准字距行高**。

### 2.2 这个项目的字体方案

⚠️ **重要约束**：微信小程序加载自定义中文字体动辄 3~5MB，直接超主包 2MB 限制。所以：

| 层级 | 字体 | 理由 |
|---|---|---|
| 界面全部正文 / 按钮 / 标签 | **系统默认**（iOS PingFang SC / 安卓思源黑体） | 零体积、渲染最快、屏幕最清晰 |
| 海报上的项目名 | 系统字体 + **字距收紧 -0.3px** | 靠字距和字重做出"展览感"，不靠换字体 |
| 大数字（分数/人数） | 系统字体 + `tabular-nums` | 等宽数字，对齐好看 |

**不下载中文字体。** 质感靠下面三件事做出来：

1. **字距**：标题收紧 `-0.02em ~ -0.04em`，正文 0
2. **行高**：标题 1.35，正文 1.7（比默认更松，这是"贵"的来源）
3. **字重**：只用 400 / 500 两档。不用 600、不用 700 —— 字重一多就廉价

### 2.3 字号阶梯（rpx）

| 用途 | 字号 | 字重 | 字距 | 行高 |
|---|---|---|---|---|
| 页面主标题 | 40rpx | 500 | -0.4rpx | 1.35 |
| 详情页大标题 | 38rpx | 500 | -0.4rpx | 1.35 |
| 区块小标题 | 24rpx | 400 | 0 | 1.5 |
| 正文 | 28rpx | 400 | 0 | 1.7 |
| 辅助说明 | 24rpx | 400 | 0 | 1.6 |
| 标签 | 22rpx | 400 | 0 | 1.2 |
| 大数字 | 48rpx | 500 | -0.5rpx | 1.1 |

### 2.4 几何规划

**一、4px 基础网格**
所有间距必须是 4 的倍数。可用值只取六档：

```
8 / 16 / 24 / 32 / 48 / 64
```

不要出现 20、28、36 这种"看起来差不多"的值。

**二、安全边距 32rpx**
页面左右留白固定 32rpx。这是呼吸感的来源，不要为了塞内容压缩它。

**三、不用卡片框**
分组靠两件事：
- **0.5px 分隔线**（`#E6E4DE`）
- **留白 32rpx 以上**

四面框住的卡片在手机上会显得拥挤，且每加一个框就多一层视觉噪音。

**四、圆角克制**
只用三个值：标签 6rpx / 按钮 12rpx / 海报 16rpx。不要什么都是 20rpx 圆角。

**五、海报占主体 52%**
详情页与首页的主体区固定占屏高约一半。上下各留一段空白，让海报"浮"在页面里。

## 三、吉祥物「小川」v3 —— 极简 3D 圆球

### 3.1 形态定义

**一颗球，只有眼睛和微笑。**

删掉的东西：黄色腹羽、耳朵、喙、翅膀、脚。全部删除。

保留：
- **球体**：径向渐变做出体积感（左上受光，右下转暗）
- **高光**：左上角一块柔和的白色椭圆反光
- **接影**：球体下方一小片渐深阴影，让球"落地"
- **眼睛**：两个深色竖椭圆 + 双白高光点
- **腮红**：两片极淡的粉色椭圆（透明度 0.42）
- **嘴**：一条 4px 圆头弧线

### 3.2 配色

```
--ball-light: #C9BFF5;   /* 受光面 */
--ball-mid:   #8B7FDD;   /* 中间调 */
--ball-dark:  #5E51AC;   /* 暗面 */
--ball-edge:  #43397F;   /* 边缘 */
--face:       #1E1A33;   /* 眼睛与嘴 */
--blush:      #F08CA8;   /* 腮红，透明度 0.42 */
```

### 3.3 三个表情（全部靠弧线曲率变化）

| 状态 | 眼睛 | 嘴 | 触发 |
|---|---|---|---|
| **睁眼** | 竖椭圆 + 双高光 | `Q` 曲线，小幅微笑 | 默认待机 |
| **眨眼** | 向下弧线（`Q` 开口向下） | 同默认，略上移 | 每 3~6 秒随机，持续 120ms |
| **眯眼笑** | 向上弧线（弯月形） + 加深腮红 | 弧线曲率加大 | 成功 / 录取 |

> 全部表情只动三个地方：眼睛的形状、嘴的曲率、腮红的深浅。**不加任何新部件。**

### 3.4 跳跃动效（上下左右）

| 动效 | 位移 | 时长 | 缓动 |
|---|---|---|---|
| **上下跳**（主循环） | `translateY` 0 → -28rpx → 0 | 480ms | 上升 `ease-out`，下落 `ease-in` |
| **左右晃**（待机） | `translateX` ±6rpx + `rotate` ±4deg | 2400ms | `ease-in-out`，无限循环 |
| **四向弹跳**（反馈） | 朝点击方向 `translate` 20rpx 后回弹 | 320ms | `cubic-bezier(.34,1.56,.64,1)` |
| **落地压扁** | `scaleY` 0.92 + `scaleX` 1.06 | 80ms | 瞬时 |

### 3.5 实现要点

**① 只动 transform**
位移用 `translate3d`，形变用 `scale`。绝不碰 `top` / `left` / `width` / `height`，否则每帧重排，低端安卓掉帧。

**② 重力感靠缓动**
上升 `ease-out`（先快后慢），下落 `ease-in`（先慢后快）。这一条是"自然"和"机械"的分界。

**③ 影子同步缩放**
球跳高时地面影子变小变淡，落地时变大变深。少了这层，球像贴纸而不是立体物。

**④ 眨眼随机不固定**
`setInterval` 固定频率会显得机械。改用递归 `setTimeout`，间隔取 `3000 + Math.random() * 3000`。

**⑤ 尊重系统设置**
```css
@media (prefers-reduced-motion: reduce) {
  .ball, .ball-shadow { animation: none; transition: none; }
}
```

### 3.6 AI 出图提示词（如需高保真素材）

```

soft purple-lavender gradient (#8B7FDD mid, #43397F edge) with light from upper left,
two simple dark oval eyes with double white highlight sparkles,

```

- `round open oval eyes` → 默认
- `eyes closed as downward arcs` → 眨眼
- `crescent moon smiling eyes` → 眯眼笑

## 四、配色系统 v3（精简约，细节同 v2）

```
--paper:      #FBFAF7;   /* 页面底，暖米白 */
--surface:    #FFFFFF;   /* 卡片面 */
--ink:        #14131A;   /* 主文字，近黑 */
--ink-2:      #55535E;   /* 次要文字 */
--ink-3:      #8E8C97;   /* 辅助/占位 */
--line:       #E6E4DE;   /* 分隔线 */
--accent:     #B5432A;   /* 唯一点缀色：陶土红 */
--accent-bg:  #FBF0EC;   /* 点缀浅底 */
--ok:  #2E7D5B;  --warn: #9A6B12;  --no: #8E3A3A;   /* 语义色，仅状态标签 */
```

**铁律**：
- 主按钮用 `--ink` 黑底白字（像美术馆指示牌），**不用彩色大按钮**
- `--accent` 一屏内出现不超过 2 处（倒计时 + 一个标签）
- 语义色只用于状态标签，不做装饰
- 不用渐变背景、不用阴影（除球体自身的立体光影）
