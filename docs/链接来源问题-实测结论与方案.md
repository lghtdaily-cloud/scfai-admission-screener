## 二、微信链接获取能力 · 实测结论

这是本次最重要的发现，直接决定方案可行性。

### 测试 1：`wechat-article-search` 脚本返回的链接类型

搜狗微信搜索返回的是**中转链接**，不是真实微信链接：

```
https://weixin.sogou.com/link?url=dn9a_-gY295K0Rci_xozVXfdMkSQTLW...
```

### 测试 2：中转链接能否自动解析为真实微信链接

编写 `resolve-wx.js`，用完整浏览器请求头 + Referer 尝试解析：

```
解析结果: 成功 0 / 失败 6
失败原因分布: {"captcha":6}
```

**6 条全部触发验证码。**

### 测试 3：直接探测搜狗中转链接的真实响应

```
状态码: 302
重定向 Location: http://weixin.sogou.com/antispider/?from=%2Flink%3Furl%3D...
含 antispider : true
提取到微信链接 : (无)
```

**搜狗直接 302 跳转到反爬页面，不返回真实链接。**

### 测试 4：用 `allowed_domains: mp.weixin.qq.com` 限定域搜索

即使把搜索域限定在 `mp.weixin.qq.com`，返回结果的 `URL` 字段**依然为空**。

**原因**：微信公众号内容对外封闭，文章链接只能在微信 App / 微信内浏览器站内访问，外部搜索引擎无法稳定索引到文章 URL（大量内容仅存于 App 内，不被外部抓取）。

### 测试 5：`-r` 参数（脚本自带的链接解析）

```
总数: 0
```

`-r` 参数同样被反爬拦截，返回空。

## 三、结论（硬约束）

| 能力 | 可行性 | 说明 |
|---|---|---|
| 用搜狗微信**发现**活动线索（标题+摘要+发布时间） | ✅ 可以 | 脚本稳定可用 |
| 用搜狗微信**拿到**真实 `mp.weixin.qq.com` 链接 | ❌ **不可能** | 反爬 + 验证码 + 站内封闭 |
| 用全网搜索发现活动线索 | ✅ 可以 | 能拿到完整正文摘要 |
| 用全网搜索拿到微信文章 URL | ❌ **不可能** | 微信内容对外封闭 |

**核心矛盾**：微信链接必须"从微信里拿"，而所有外部工具都进不去微信。

## 四、可行方案

### 方案 A：链接留空 + 标题精确可搜（推荐，零人工）

- 收录活动时，`url` 字段**留空**
- 同时写入 `wechatHint` 字段：**公众号名称 + 文章标题**
- 前端展示时，不显示"打开原文"按钮，改为显示"在微信搜索：<公众号名> — <标题>"
- 用户复制这串文字到微信搜索框，第一条就是原文

**优点**：完全自动、链接永不失效、指向明确
**缺点**：需要用户手动复制到微信搜一下（1 步操作）

### 方案 B：只收录能确认微信链接的活动（最严格）

- 只收录正文里**自带公众号名称且能被人工核验**的活动
- 由于无法自动获取链接，实际上退化为"人工补充链接"

**缺点**：自动化程度大幅降低

### 方案 C：链接指向公众号主页而非文章（折中）

- 部分搜狗结果能拿到公众号的 `__biz` 参数，可拼出公众号主页链接
- 但主页链接仍需微信内打开

### 方案 D：改用非微信信息源（背离用户要求）

用户明确要求微信链接，不采纳。

## 六、给用户的建议

**最实际的做法**：我每天检索出**活动线索**（标题、公众号、时间、摘要），
在网站首页以卡片展示，卡片上的操作是「复制标题，去微信搜索」。

这样：
- ✅ 你不会点开打不开的链接
- ✅ 所有信息都能在微信里找到原文
- ✅ 全自动，无需人工维护链接
